## 我的整体建议

### 文案定位调整

把 `assessment.html` 从「雇主担保评估」重新定位为「澳洲移民/留学综合评估入口」。首页标题和引导语要覆盖：
- 技术移民 / 雇主担保
- 留学（中小学、VET、高等教育）
- 临签（旅游、打工度假、陪读等）
- 家庭类（配偶、子女、父母）
- 入籍 / 续签 / 其他

这样既保留原有雇主担保线索，又为后续业务扩展留出空间。

### 页面结构优化建议

1. **顶部介绍区**
   - 标题：澳洲移民与留学评估
   - 副标题：技术移民 · 雇主担保 · 留学教育 · 签证续签
   - 服务亮点增加：企业猎聘匹配、简历优化、面试培训、持牌律师评估

2. **评估目的/服务类型**
   - 在最开始增加一组「您希望咨询的服务类型」多选
   - 选项：雇主担保移民、技术移民、留学/游学、工作签证、家庭团聚、旅游/临签、签证续签/入籍、其他
   - 后续根据选择动态显示/隐藏相关区块（可选先不做联动，仅作为标签记录）

3. **语言能力细化**
   - 每个考试类型（IELTS / PTE / TOEFL / 其他）提供：听 / 说 / 读 / 写 四个单项
   - 新增「语言成绩单」上传

4. **职业评估字段**
   - 是否已完成职业评估：可选
   - 职业评估职位（ANZSCO 或职业名称）：可选文本

5. **目标国家 → 签证类别**
   - 移除「想申请移民的国家」
   - 改为「感兴趣的签证类别/服务」多选
   - 按类别分组：
     - 技术/雇主类：186、482、494、190、189、491
     - 工作/培训类：407、408、400、462/417
     - 留学类：500 中小学、500 VET、500 高等教育、590 陪读、短期游学/插班
     - 旅游/临签：600 旅游、602 医疗
     - 人才/投资：NIV 858、188/888 等
     - 家庭类：309/100 配偶、445/101/102 子女、143/103 父母、870
     - 其他：866 庇护、155/157 续签、入籍、部长干预

6. **文件上传扩展**
   - 统一为「文件资料上传区」
   - 文件类型标签：简历、语言成绩单、学历证明、成绩单、职业评估信、其他
   - 技术上可改为多个独立上传框，避免用户只传一个文件

7. **教育背景**
   - 增加「游学/插班/中小学留学意向」选项或备注

8. **联系方式**
   - 手机改为可选或「手机/微信至少填一个」

## 数据库影响评估

当前 `candidate_assessments` 表已有字段：
- `ielts_score`, `pte_score`, `other_english_score` → 可替换为 `ielts_listening/speaking/reading/writing`, `pte_...`
- `skills_assessed` (yes/no) → 改为 `skills_assessed_occupation` (text) + `has_skills_assessment` (bool)
- `target_country` → 可改为 `visa_categories` (text)
- 新增：`language_score_url`, `education_cert_url`, `transcript_url` 或统一 `document_urls` (json)

**建议**：由于表已有生产数据，优先采用「新增字段」而非「删除旧字段」，保留旧字段兼容性。
